# New-Label

## SYNOPSIS

Create a label

## SYNTAX

### __AllParameterSets

```
New-Label [-Name] <string> -Color <string> [-Description <string>] [-Priority <int>]
 [-Group <string>] [-Repo <string>] [-Forge <string>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION


Creates a label on GitHub or GitLab. `-Color` is a hex value the forge stores as given.

## EXAMPLES

### Example 1

New-Label 'bug' -Color d73a4a -Description 'Something is broken'
