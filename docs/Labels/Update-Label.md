# Update-Label

## SYNOPSIS

Update a label

## SYNTAX

### __AllParameterSets

```
Update-Label [-Name] <string> [-NewName <string>] [-Color <string>] [-Description <string>]
 [-Priority <int>] [-Group <string>] [-Repo <string>] [-Forge <string>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION


Changes a label's name, color, or description on GitHub or GitLab. The label is identified by
its current `-Name`; `-NewName` renames it.

GitLab keys its write endpoints on a numeric label id, so the name is resolved to an id before
dispatch.

## EXAMPLES

### Example 1

Update-Label 'bug' -NewName 'defect' -Color b60205
