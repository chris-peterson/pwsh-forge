# Remove-Label

## SYNOPSIS

Delete a label

## SYNTAX

### __AllParameterSets

```
Remove-Label [-Name] <string> [-Group <string>] [-Repo <string>] [-Forge <string>] [-WhatIf]
 [-Confirm]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION


Deletes a label from a repository or group on GitHub or GitLab.

GitLab keys its write endpoints on a numeric label id, so the name is resolved to an id before
dispatch.

## EXAMPLES

### Example 1

Remove-Label 'bug'
