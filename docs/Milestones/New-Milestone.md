# New-Milestone

## SYNOPSIS

Create a milestone

## SYNTAX

### __AllParameterSets

```
New-Milestone [-Title] <string> [-Description <string>] [-DueDate <string>] [-StartDate <string>]
 [-State <string>] [-Group <string>] [-Repo <string>] [-Forge <string>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION


Creates a milestone on GitHub or GitLab.

GitHub accepts an initial `-State`; GitLab does not, so a milestone created there starts open
and `Update-Milestone -State` closes it.

## EXAMPLES

### Example 1

New-Milestone 'v1.0' -DueDate 2026-12-31
