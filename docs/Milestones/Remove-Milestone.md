# Remove-Milestone

## SYNOPSIS

Delete a milestone

## SYNTAX

### __AllParameterSets

```
Remove-Milestone [-Id] <string> [-Group <string>] [-Repo <string>] [-Forge <string>] [-WhatIf]
 [-Confirm]
 [<CommonParameters>]
```

## ALIASES

## DESCRIPTION


Deletes a milestone from a repository or group on GitHub or GitLab.

## EXAMPLES

### Example 1

Remove-Milestone 3
